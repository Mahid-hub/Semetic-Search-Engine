Python is a high-level programming language known for its readable syntax.

Variables:
Python variables are created by assigning a value to a name.

Functions:
Functions are defined using the def keyword. A function can accept parameters
and return a value.

Lists:
Lists are ordered, mutable collections. Items can be accessed using indexes.

Dictionaries:
Dictionaries store key-value pairs. A value can be retrieved using its key.

Classes:
Classes are used to create objects and define their attributes and methods.

Exceptions:
Python uses try and except blocks to handle exceptions.

Modules:
A Python module is a file containing Python definitions and statements.
Modules can be imported into other Python programs.
